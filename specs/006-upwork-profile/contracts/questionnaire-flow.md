# Contract: Questionnaire Flow

**Feature**: 006-upwork-profile

## Fixed Question

Every collection run starts with a brand-new draft:

```bash
PYTHONPATH=src python3 -m upwork_profile.cli init-draft \
  --output tmp/upwork-profile-draft.json
```

### Q1 — Profile Link (optional)

**Prompt**: `Paste your Upwork profile link (upwork.com/freelancers/...) or skip.`

**Options**:
- `provide_link` — Enter Upwork profile URL
- `skip_link` — Skip and continue to gap questions

**Rules**:
- User may paste URL in the same reply or the next chat message without re-asking Q1.
- Invalid URL → error, offer skip or new link.
- On skip: `input_mode: questionnaire_only`, proceed to gap questions.

**On URL**:
1. Browser Tab → open profile link.
2. If login wall appears, pause and ask user to authenticate manually.
3. Capture page text via `browser_snapshot`.
4. Run `extract-text` CLI and merge into draft with `from_resume_link` provenance.
5. Continue only with gap questions for required fields still empty.

## Dynamic Gap Questions (Q2+)

Generated by:

```bash
PYTHONPATH=src python3 -m upwork_profile.cli gaps --input tmp/upwork-profile-draft.json
```

Gap questions are in English (`schema.GAP_QUESTIONS`).

### MVP Gap Fields

| field_id | Required | Notes |
|----------|----------|-------|
| `profile_title` | yes | |
| `overview` | yes | |
| `hourly_rate` | yes | USD string |
| `skills` | yes | comma-separated tags |
| `work_experience_status` | yes | yes / no |
| `work_experience` | conditional | when status is has_experience |
| `education` | no | optional gap |
| `portfolio_links` | no | optional gap |

## Finalization

When no required gaps remain:

```bash
PYTHONPATH=src python3 -m upwork_profile.cli validate --input tmp/upwork-profile-draft.json
PYTHONPATH=src python3 -m upwork_profile.cli write --input tmp/upwork-profile-draft.json
```

Write fails if required fields are still missing.
