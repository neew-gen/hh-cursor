# Contract: Questionnaire Flow

**Feature**: 002-resume-profile

## Fixed Question

There is no Q0 in the current flow.

Every `/resume-profile` run starts with a brand-new draft:

```bash
PYTHONPATH=src python3 -m resume_profile.cli init-draft \
  --skills-mode new \
  --output tmp/profile-draft.json
```

Existing artifacts are not used as a supplement source for feature 002.

### Q1 — Resume Link (optional)

Ask this step **via `AskQuestion`**, not plain chat text.

**Prompt**: `Введите сюда ссылку на ваше резюме на HeadHunter (hh.ru).`

**Options**:
- `provide_link` — `Ввести ссылку на ваше резюме`
- `skip_link` — `Пропустить этот шаг и перейти к вопросам`

**Rules**:
- Do **not** ask a preliminary yes/no question like «Будете ли вы вводить ссылку?».
- User must be able to paste the hh.ru resume URL through the same `AskQuestion` flow using `Other`.
- If the user selected `provide_link` but no URL string was captured by `AskQuestion`, the agent must wait for the very next plain chat message and treat it as the expected resume link input instead of re-asking Q1.
- In that case the agent may send one plain chat line such as «Вставьте ссылку на резюме hh.ru и отправьте сообщение.» and MUST NOT show a second `AskQuestion` or any intermediate questionnaire form.
- Skipping this step must immediately continue to the first gap question.

**On URL**:
1. Browser Tab → open resume link.
2. If login/captcha appears, pause and ask the user to authenticate manually.
3. On the resume page, click `Скачать` and choose `Простой текст · txt`.
4. Follow the resulting `resume_converter/...type=txt` URL in the same browser session.
5. Treat the response as a full HTML resume document, not as plain text.
6. Run deterministic extract from the download HTML and merge the extracted fields into the draft with `from_resume_link`.
7. Continue only with gap questions for required fields that remain empty after merge.

**On Skip**: `input_mode: questionnaire_only`, proceed to gap questions.

## Dynamic Gap Questions (Q2+)

Generated by `PYTHONPATH=src python3 -m resume_profile.cli gaps --input <draft.json>`.

Ask **one gap at a time** (or two related fields max), using `AskQuestion` in Cursor.

Each gap in CLI output includes `ask_options`. Use them **verbatim** — do not invent choices.

| Rule | Detail |
|------|--------|
| Option source | Current draft JSON only (`tmp/profile-draft.json`) |
| Forbidden source | Other artifact files (except Q0 load), prior chat runs, guessed roles |
| Defer option | `defer_to_chat` — «Отвечу в следующем сообщении» — **always last** |
| On defer | Wait for free-form user text in chat before merging draft |

| field_id | Gap question (RU) |
|----------|-------------------|
| `target_role` | С ссылкой: «Какая желаемая должность указана в резюме?»; без ссылки: «Какая ваша желаемая должность?» |
| `specializations` | Укажите специализации (до 5), через запятую. |
| `work_experience_status` | Есть ли у вас опыт работы? (да / нет) |
| `work_experience` | Опишите место работы: компания, должность, период (месяц/год), обязанности и достижения. |
| `skills.hard` | Какие ключевые навыки и уровень владения (базовый / средний / продвинутый)? |
| `education` | Где вы учились: учебное заведение, специальность, степень, год окончания? |
| `no_formal_education` | Нет формального образования для указания в резюме? (да / нет) |
| `about_me` | Расскажите о себе для блока «Обо мне» на hh.ru (можно несколько абзацев). |

Gap `about_me` is **optional** (`required: false`): artifact write succeeds without it, but the questionnaire asks when the field is empty after extract.

For `about_me`, accept **free-form chat text** or **macOS dictation** (AskQuestion has no native voice input).

Optional fields not in gap list: `work_preferences`, `languages`.

## Completion

When all **required** gaps are filled and `validate` reports `complete: true`:

```bash
PYTHONPATH=src python3 -m resume_profile.cli write --input draft.json
```

Default output: `artifacts/resume-profile/<target-role-slug>.yaml`.

If that file already exists, write a new artifact with a numeric suffix in parentheses:
`<target-role-slug> (2).yaml`, `<target-role-slug> (3).yaml`, and so on.

## Error Handling

| Condition | Action |
|-----------|--------|
| Invalid URL | Ask again or offer skip |
| Login/captcha | Pause; user logs in; retry extract |
| Download `txt` opens `resume_converter/...type=txt` | Treat response as HTML download document and parse stable resume blocks |
| Empty required answer | Re-ask same gap question |
| Partial extract | Fill known fields; gap for rest |
